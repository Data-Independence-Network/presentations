# Прикладное направление «УраТур»: База знаний и архитектурные исходные материалы

В данном каталоге собраны концептуальные проектные материалы, исходные данные дознания и архитектурные спецификации для флагманского прикладного решения экосистемы «Турбаза» — децентрализованного туристического навигатора и краеведческого реестра **«УраТур»**.

---

## Реестр документов

1. [`UraTur_Public_Tags_and_Index_Cooperatives.md`](UraTur_Public_Tags_and_Index_Cooperatives.md)  
   **Общественные теги, самобалансирующиеся хронологические деревья и кооперативная индексная сеть в «УраТуре»**  
   *Ключевые темы:*
   - Различие между персональными внешними метками («Деловой») и открытыми общественными тегами («УраТур»);
   - Кооперативы энтузиастов и аренда домашних стационарных компьютеров как легковесных индексных серверов;
   - Самобалансирующееся хронологическое дерево (Temporal B+ Tree / LSM) с вставкой в середину и богатой временной пагинацией;
   - Серверы сборки групп тегов, опрос селективности и соединение от меньшего к большему (Leapfrog Triejoin);
   - Сверхоперативное сохранение популярных срезов (FIFO, LRU, топ-1000 новейших);
   - Устройства пользователей (Листья) как локальные узлы сборки без внешних серверов.
