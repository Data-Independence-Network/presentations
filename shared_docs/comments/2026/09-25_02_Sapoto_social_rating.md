Социальный рейтинг пользователей будет поддерживаться через индексацию Случаев в которых участвовали пользователи.  Используя систему схожую с системой вывода результатов микро-опросов КубГолоса тематические и географические Ветки и Ветви будут выводить отдельные и общие рейтинги пользователей по определенным темам и агрегируя их вверх по тематическому дереву.  Рейтинг пользователей будет выводиться и по месту проживания, дублируя географически привязанный социальный рейтинг пользователей в Ветви Региона и Ствол страны для поиска с других Веток.
