# AGENTS.md — shared_docs/comments

## 🎯 Назначение и контекст (Purpose & Scope)
В этой директории собраны **личные авторские записи разработчика и создателя платформы «Турбаза»**, написанные **вручную человеком без использования искусственного интеллекта**.

Здесь зафиксированы:
- Первоначальные идеи, история зарождения и логика эволюции концепций платформы.
- Глубинная мотивация ключевых архитектурных решений (автономные хранилища, реляционные внешние ключи между хранилищами, отделение приложений от данных, древовидная топология, интернет данных).
- Семантически размеченные факты и принципы взаимодействия компонентов.

## 🏷️ Семантическая разметка (%Labels)
Для упрощения навигации и точного поиска фактов ИИ-агентами автор использует систему **семантических меток** (`%Label`), которые ставятся в начале параграфов или непосредственно под заголовками (см. [`LABELS.md`](file:///home/anastasiya/Documents/presentations/shared_docs/comments/LABELS.md)).

### Словарь ключевых меток:
| Метка | Понятие | Описание в контексте архитектуры |
|---|---|---|
| `%ActorId` | Ключ Субъекта | Идентификатор владельца / субъекта данных (пользователя, семьи, организации) |
| `%API` | Общественная Оболочка | Публичный интерфейс приложения для записи данных в его схему и переиспользования логики |
| `%App` | Приложение | Программный модуль со своей схемой данных, отделенный от хранилища пользователя |
| `%Branch` | Ветка | Промежуточный узел агрегации древовидной структуры |
| `%Cooperation` | Взаимодействие | Механизмы взаимодействия приложений на уровне данных (FK, JOIN) и бизнес-логики (API) |
| `%Database` | База Данных | Реляционные схемы приложений и табличные структуры |
| `%ForeignKey` | Внешние ключи | Стандартные связи между записями в разных хранилищах; обеспечивают взаимосвязь при автономности |
| `%Internet` | Интернет | «Интернет данных» — объединение независимых древовидных структур подобно лесной микоризе |
| `%Join` | SQL-соединение | Чтение и объединение данных схем разных приложений напрямую через SQL JOIN |
| `%Leaf` | Лист | Периферийный суверенный узел древовидной структуры |
| `%Queue` | Очередь | Очереди с возможностью поиска для быстрого извлечения недавно добавленных записей |
| `%RecordId` | Ключ Записи | Идентификатор конкретной записи внутри хранилища |
| `%Repository` | Хранилище | Единица знаний; охватывает реляционные таблицы, хранит актуальные копии внешних записей |
| `%RepositoryId` | Ключ Хранилища | Уникальный идентификатор хранилища |
| `%Screen` | Экран | Экран приложения и логика его первоначальной загрузки |
| `%Tree` | Дерево | Серверная древовидная структура для хранения и подачи данных по гео- и тематическому признаку |
| `%UI` | Интерфейс | Пользовательский интерфейс, загружающий экран из локального хранилища |
| `%User` | Пользователь | Владелец данных, независимый от приложений |

## 📋 Правила и инструкции для ИИ-агентов (Guidelines for AI Agents)

1. 🔒 **Строгий режим только для чтения (Read-Only):**
   - ИИ-агентам **запрещено** создавать, изменять или удалять файлы авторских заметок в директории `shared_docs/comments/` (за исключением файлов `AGENTS.md`).
   - Эти записи являются неизменяемым историческим первоисточником мыслей разработчика.

2. 🧠 **Первоисточник архитектурного замысла (Source of Author Intent):**
   - При подготовке презентаций, слайдов, пояснительных записок и технической документации агент обязан опираться на эти записи для точной передачи терминологии и философии платформы.
   - Особое внимание обращать на фундаментальные принципы: *отделение приложений от данных*, *суверенитет хранилищ при сохранении внешних связей*, *микоризная сеть интернета данных*.

3. 🔍 **Использование семантических меток при поиске:**
   - При исследовании контекста используйте точечный поиск `grep_search` по меткам (например `Query: "%ForeignKey"`, `Query: "%Queue"`, `Query: "%API"`), чтобы находить параграфы с точной позицией разработчика.

4. 🔄 **Связывание с технической спецификацией:**
   - Сопоставляйте авторские заметки из `comments/` с формальными спецификациями в [`Технический документ платформы Турбаза.md`](file:///home/anastasiya/Documents/presentations/shared_docs/%D0%A2%D0%B5%D1%85%D0%BD%D0%B8%D1%87%D0%B5%D1%81%D0%BA%D0%B8%D0%B9%20%D0%B4%D0%BE%D0%BA%D1%83%D0%BC%D0%B5%D0%BD%D1%82%20%D0%BF%D0%BB%D0%B0%D1%82%D1%84%D0%BE%D1%80%D0%BC%D1%8B%20%D0%A2%D1%83%D1%80%D0%B1%D0%B0%D0%B7%D0%B0.md) для формирования целостной картины платформы.
