# Метки

Метки позволяют искусственному интеллекту легче находить факты связанные с определенными концепциями.  Метки ставятся в начале параграфа или под заголовком.  Например:

## Заголовок
%Repository %ForeignKey

%UI
Начало параграфа...

## Метки

%Repository - Хранилище
%ForeignKey - Внешние ключи
%RepositoryId - Ключ Хранилища
%ActorId - Ключ Субъекта 
%RecordId - Ключ Записи
%UI - Интерфейс 
%Screen - Экран
%App - Приложение
%Cooperation - Взаимодействие
%Database - База Данных
%Join - SQL-соединение
%API - Общественная Оболочка
%Tree - Дерево
%Queue - Очередь
%Internet - Интернет
%User - Пользователь
%Branch - Ветка
%Leaf - Лист
