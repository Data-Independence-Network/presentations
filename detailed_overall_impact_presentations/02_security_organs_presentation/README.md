# Платформа «Турбаза»
## Турбаза для Органов Безопасности и Правопорядка: Неуязвимый суверенный криптоконтур и ликвидация баз-мишеней

> **Категория:** [Detailed Overall Impact (Детальный анализ стейкхолдеров)](../README.md)  
> **Идентификатор:** `02_security_organs_presentation` | **Слайдов:** 15 | **Формат:** 16:9 Full HD (1920x1080)  
> **Озвучка:** Edge Neural TTS (`ru-RU-DmitryNeural`, темп `-9%`, тон `-5Hz`) | **Хронометраж:** ~11:30–12:30 мин  
> **Стиль оформления:** Detailed Impact (Багровый Щит) (`#ff2a5f`)

## 🎯 Концепция и ключевая цель

Анализ платформы с точки зрения органов безопасности и правопорядка: ликвидация единых баз-мишеней (Honeypots), криптографическая защита ГОСТ Р 34.12/34.10, выявление преступных аномалий по метаданным без вскрытия тайны частной жизни и ведомственная изоляция контуров.

**Целевая аудитория презентации:** Руководители силовых ведомств, офицеры информационной безопасности, специалисты по противодействию киберугрозам.

## 🔑 Ключевые архитектурные концепции и технологии

- **Ликвидация мега-мишеней:** Отсутствие единого сервера делает физически невозможной кражу баз данных миллионов граждан.
- **Криптографический стандарт ГОСТ:** Национальные шифры «Кузнечик» и «Магма» прямо на аппаратных модулях устройств.
- **Анализ графов связей (%Analytics):** Выявление экстремистских и мошеннических паттернов по топологии вызовов без чтения переписки.
- **Ведомственные герметичные контуры:** Разделение данных различных силовых ведомств с доступом только по регламентированным шлюзам.
- **Непрерывность связи при угрозах:** Защищенная локальная координация подразделений при подавлении внешних каналов связи.

## 🚀 Просмотр и сборка

### Просмотр через веб-сервер
1. Запустите единый локальный веб-сервер в корне хранилища:
   ```bash
   ./start_presentation.sh
   ```
2. Откройте интерактивную презентацию в браузере:
   ```
   http://localhost:8080/detailed_overall_impact_presentations/02_security_organs_presentation/generated/outputs/web_deck/
   ```
   *(Управление: Пробел / Стрелки — переключение слайдов; Кнопка «Автовоспроизведение» — синхронный показ со звуком).*

### Команды сборки

**Автономная офлайн-сборка (Offline Rebuild, без API-ключа):**
```bash
# Из папки этой презентации:
node rebuild.js

# Из папки категории (detailed_overall_impact_presentations):
npm run rebuild-security-organs

# Из корня хранилища:
npm --prefix detailed_overall_impact_presentations run rebuild-security-organs
```

**Регенерация дикторской речи через Neural TTS (требует API-ключ в корне):**
```bash
# Из папки этой презентации:
node regenerate.js

# Из папки категории (detailed_overall_impact_presentations):
npm run regen-security-organs
```
