## 🎯 Концепция и ключевая цель

Государственный масштаб: колоссальная разгрузка государственных ЦОД на 80–90%, непрерывная доступность жизненно важных муниципальных услуг при авариях и отключении интернета, локализация трафика внутри страны и надежный фундамент цифрового суверенитета.

**Целевая аудитория презентации:** Руководители Минцифры, региональные министры информатизации, мэры городов, руководители ЦОД.

## 🔑 Ключевые архитектурные концепции и технологии

- **Разгрузка опорных ЦОД на 80%:** Перенос вычислений на клиентский Edge разгружает государственные серверы и экономит бюджетные миллиарды.
- **Непрерывность госуслуг при ЧС:** Районные Ветки продолжают выдавать справки и координировать службы даже при обрыве магистралей.
- **100% импортозамещение на кремнии:** Работа на отечественных процессорах «Байкал» и «Эльбрус» в окружении операционных систем на базе Linux.
- **Муниципальная прозрачность:** Опросы «КубГолоса» дают объективную картину настроений жителей без фальсификаций и ботов.
- **Национальный депозитарий на Стволе:** Надежное вечное хранение эталонных юридических реестров государства.

## 🚀 Просмотр и сборка

### Просмотр через веб-сервер
1. Запустите единый локальный веб-сервер в корне хранилища:
   ```bash
   ./start_presentation.sh
   ```
2. Откройте интерактивную презентацию в браузере:
   ```
   http://localhost:8080/detailed_overall_impact_presentations/06_government_infra_presentation/generated/outputs/web_deck/
   ```
   *(Управление: Пробел / Стрелки — переключение слайдов; Кнопка «Автовоспроизведение» — синхронный показ со звуком).*

### Команды сборки

**Автономная офлайн-сборка (Offline Rebuild, без API-ключа):**
```bash
# Из папки этой презентации:
node rebuild.js

# Из папки категории (detailed_overall_impact_presentations):
npm run rebuild-government-infra

# Из корня хранилища:
npm --prefix detailed_overall_impact_presentations run rebuild-government-infra
```

**Регенерация дикторской речи через Neural TTS (требует API-ключ в корне):**
```bash
# Из папки этой презентации:
node regenerate.js

# Из папки категории (detailed_overall_impact_presentations):
npm run regen-government-infra
```
