# Платформа «Турбаза»
## Турбаза для Граждан и Домохозяйств: Владение собственной информацией и абсолютная защита личной жизни

> **Категория:** [Detailed Overall Impact (Детальный анализ стейкхолдеров)](../README.md)  
> **Идентификатор:** `01_citizens_presentation` | **Слайдов:** 15 | **Формат:** 16:9 Full HD (1920x1080)  
> **Озвучка:** Edge Neural TTS (`ru-RU-DmitryNeural`, темп `-9%`, тон `-5Hz`) | **Хронометраж:** ~11:30–12:30 мин  
> **Стиль оформления:** Detailed Impact (Электрик Циан) (`#00f0ff`)  

---

## 🎯 Концепция и ключевая цель

Индивидуальный отраслевой анализ влияния платформы на граждан и семьи: неприкосновенность личной жизни, 0 байт персональных данных у посторонних лиц, скорость работы интерфейса < 1 мс, семейный контур управления делами и добрососедская взаимопомощь.

**Целевая аудитория презентации:** Граждане, семьи, ассоциации защиты прав потребителей, общественные организации.

## 🔑 Ключевые архитектурные концепции и технологии

- **Священный сейф семьи:** Личные фото, документы, медицинские записи и переписка хранятся строго дома на своих устройствах.
- **Защита от спама и слежки:** Ни один банк или маркетплейс больше не может звонить с навязчивыми предложениями.
- **Семейный контур:** Совместные списки покупок, поручения детям и расписание без риска утечек.
- **Добрососедство в «Заботе»:** Реальная взаимовыручка в подъезде и доме без токсичности публичных соцсетей.
- **Социальное восстановление по Шамиру:** Восстановление доступа к архивам через доверенных родственников без паролей в облаке.

## 🚀 Просмотр и сборка

### Просмотр через веб-сервер
1. Запустите единый локальный веб-сервер в корне хранилища:
   ```bash
   ./start_presentation.sh
   ```
2. Откройте интерактивную презентацию в браузере:
   ```
   http://localhost:8080/detailed_overall_impact_presentations/01_citizens_presentation/generated/outputs/web_deck/
   ```
   *(Управление: Пробел / Стрелки — переключение слайдов; Кнопка «Автовоспроизведение» — синхронный показ со звуком).*

### Команды сборки

**Автономная офлайн-сборка (Offline Rebuild, без API-ключа):**
```bash
# Из папки этой презентации:
node rebuild.js

# Из папки категории (detailed_overall_impact_presentations):
npm run rebuild-citizens

# Из корня хранилища:
npm --prefix detailed_overall_impact_presentations run rebuild-citizens
```

**Регенерация дикторской речи через Neural TTS (требует API-ключ в корне):**
```bash
# Из папки этой презентации:
node regenerate.js

# Из папки категории (detailed_overall_impact_presentations):
npm run regen-citizens
```
