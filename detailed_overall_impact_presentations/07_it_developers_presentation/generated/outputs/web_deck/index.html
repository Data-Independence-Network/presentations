Как устроена экономика API в платформе Турбаза?

В платформе реализована математически выверенная модель разделения доходов на базе теории игр.

Когда приложение генерирует доход — будь то показ рекламы или прямая оплата услуг пользователем — система анализирует криптографический след вызова.

Доход делится на эн равных частей между всеми создателями задействованных компонентов.

Если в приложении использован визуальный интерфейс одного автора, алгоритм расчета другого инженера и реляционная схема данных третьего разработчика — каждый из них автоматически получает ровно одну треть от пула вознаграждения.

Это гарантирует, что труд создателей открытых библиотек и качественных схем данных наконец-то получает достойную финансовую оценку.

БЕЗОПАСНОСТЬ И ПЕСОЧНИЦА ИСПОЛНЕНИЯ

Sandboxed Execution: изолированная среда, отсутствие утечек ключей и гарантии «Read-Anywhere, Write-Self»

АРХИТЕКТУРНАЯ ИЗОЛЯЦИЯ КОДА
  • Изоляция в Sandboxed Web Worker / IFrame: Приложения исполняются в герметичных песочницах без прямого доступа к файловой системе или сетевым сокетам.
  • Гарантия Read-Anywhere, Write-Self: Приложения могут выполнять SQL SELECT к любым открытым схемам платформы, но запись возможна строго через авторизованные вызовы `@Api()`.
  • Защита криптографических ключей: Приложение никогда не видит приватный ключ пользователя: подписание транзакций выполняет ядро Листа через биометрию.
  • Неизменяемый реестр авторства: Хеш кода и версий жестко фиксируется в реестре Ствола, гарантируя защиту интеллектуальной собственности.
