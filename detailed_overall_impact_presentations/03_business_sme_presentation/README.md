# Платформа «Турбаза»
## Турбаза для Малого, Среднего и Крупного Бизнеса: Снижение TCO на 85%, локальный учет и прямая торговля без посредников

> **Категория:** [Detailed Overall Impact (Детальный анализ стейкхолдеров)](../README.md)  
> **Идентификатор:** `03_business_sme_presentation` | **Слайдов:** 15 | **Формат:** 16:9 Full HD (1920x1080)  
> **Озвучка:** Edge Neural TTS (`ru-RU-DmitryNeural`, темп `-9%`, тон `-5Hz`) | **Хронометраж:** ~11:30–12:30 мин  
> **Стиль оформления:** Detailed Impact (Изумрудный) (`#00e676`)

## 🎯 Концепция и ключевая цель

Экономический разбор эффекта платформы для предпринимателей: сокращение серверных затрат (TCO) на 85%, работа без риска штрафов по 152-ФЗ, ликвидация монопольных поборов агрегаторов (до 35%), прямые продажи клиентам шаговой доступности и смарт-контракты расчетов.

**Целевая аудитория презентации:** Владельцы бизнеса, генеральные директора, финансовые директора (CFO), руководители предприятий торговли и услуг.

## 🔑 Ключевые архитектурные концепции и технологии

- **Нулевой TCO клиентских баз:** Данные клиентов хранятся у самих клиентов — бизнесу не нужно арендовать терабайты облаков.
- **0 рисков по 152-ФЗ:** Предприятие не хранит персональные данные покупателей и защищено от миллионных штрафов за утечки.
- **Отказ от комиссии маркетплейсов:** Прямой контакт с покупателем в радиусе района без отдачи 20–35% платформе.
- **Мгновенный локальный учет:** Работа складских и кассовых программ прямо на смартфонах и ПК сотрудников без зависимости от интернета.
- **Смарт-контракты в Цифровом рубле:** Гарантия оплаты по факту отгрузки товара без банковских задержек и комиссий за эквайринг.

## 🚀 Просмотр и сборка

### Просмотр через веб-сервер
1. Запустите единый локальный веб-сервер в корне хранилища:
   ```bash
   ./start_presentation.sh
   ```
2. Откройте интерактивную презентацию в браузере:
   ```
   http://localhost:8080/detailed_overall_impact_presentations/03_business_sme_presentation/generated/outputs/web_deck/
   ```
   *(Управление: Пробел / Стрелки — переключение слайдов; Кнопка «Автовоспроизведение» — синхронный показ со звуком).*

### Команды сборки

**Автономная офлайн-сборка (Offline Rebuild, без API-ключа):**
```bash
# Из папки этой презентации:
node rebuild.js

# Из папки категории (detailed_overall_impact_presentations):
npm run rebuild-business-sme

# Из корня хранилища:
npm --prefix detailed_overall_impact_presentations run rebuild-business-sme
```

**Регенерация дикторской речи через Neural TTS (требует API-ключ в корне):**
```bash
# Из папки этой презентации:
node regenerate.js

# Из папки категории (detailed_overall_impact_presentations):
npm run regen-business-sme
```
