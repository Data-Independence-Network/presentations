МОДЕЛЬ ТЕНЕВОГО КОНТУРА (SHADOW EDGE)

Параллельное сосуществование: старая база продолжает жить, пока Турбаза берет на себя нагрузку

Разгрузка без остановки и риска:

Рядом с существующим сервером базы данных разворачивается шлюз Branch Adapter. Запросы на чтение и валидацию данных начинают исполняться на смартфонах и кассах Листьях, снимая пиковые нагрузки с центрального ядра.

Асинхронная запись в Legacy

В чем заключается инженерная магия теневого контура Shadow Edge?

Старая база данных не отключается: рядом с ней разворачивается легковесный шлюз Branch Adapter.

Этот адаптер слушает журнал изменений центральной базы и формирует компактные реляционные индексы для узлов Турбазы.

Клиентские устройства — кассовые аппараты магазинов, планшеты врачей или смартфоны граждан — начинают запрашивать данные локально из собственной быстрой памяти.

В результате до девяноста процентов нагрузки на чтение мгновенно снимается с центрального сервера.

Старая база данных вздыхает с облегчением: исчезают зависания и очереди блокировок, а все новые операции возвращаются в нее через надежную асинхронную очередь.
