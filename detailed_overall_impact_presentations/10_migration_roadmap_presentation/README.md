# Платформа «Турбаза»
## Дорожная Карта Внедрения и Legacy-мосты: Бесшовный переход к распределенному Edge без остановки процессов

> **Категория:** [Detailed Overall Impact (Детальный анализ стейкхолдеров)](../README.md)

## 🎯 Концепция и ключевая цель

Практический пошаговый план внедрения: 4-фазная дорожная карта миграции (НИОКР и пилоты → Районные Ветки → Федеральный контур → Международный шлюз БРИКС), архитектура двусторонних Legacy-мостов к существующим реляционным базам и минимизация рисков переходного периода.

**Целевая аудитория презентации:** Руководители цифровой трансформации (CDTO), менеджеры масштабных ИТ-проектов, интеграторы, госорганы.

## 🔑 Ключевые архитектурные концепции и технологии

- **4 фазы перехода:** Фаза 0 (Концепция и пилоты) $\to$ Фаза 1 (Муниципальные Ветки) $\to$ Фаза 2 (Федерация) $\to$ Фаза 3 (БРИКС+).
- **Двусторонние Legacy-мосты:** Работа поверх существующих баз PostgreSQL/MySQL через адаптеры без остановки текущих ИТ-систем.
- **Параллельный запуск:** Постепенное переключение трафика с централизованных серверов на локальные хранилища пользователей.
- **Обучение и сертификация:** Формирование национальной базы инженеров и стандартов разработки безопасного Edge-софта.
- **Контрольные точки успеха:** Четкие измеримые KPI на каждом этапе развертывания национальной инфраструктуры.

## 🚀 Просмотр и сборка

### Просмотр через веб-сервер
1. Запустите единый локальный веб-сервер в корне хранилища:
   ```bash
   ./start_presentation.sh
   ```
2. Откройте интерактивную презентацию в браузере:
   ```
   http://localhost:8080/detailed_overall_impact_presentations/10_migration_roadmap_presentation/generated/outputs/web_deck/
   ```
   *(Управление: Пробел / Стрелки — переключение слайдов; Кнопка «Автовоспроизведение» — синхронный показ со звуком).*

### Команды сборки

**Автономная офлайн-сборка (Offline Rebuild, без API-ключа):**
```bash
# Из папки этой презентации:
node rebuild.js

# Из папки категории (detailed_overall_impact_presentations):
npm run rebuild-migration-roadmap

# Из корня хранилища:
npm --prefix detailed_overall_impact_presentations run rebuild-migration-roadmap
```

**Регенерация дикторской речи через Neural TTS (требует API-ключ в корне):**
```bash
# Из папки этой презентации:
node regenerate.js

# Из папки категории (detailed_overall_impact_presentations):
npm run regen-migration-roadmap
```
