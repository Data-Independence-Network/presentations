# Платформа «Турбаза»
## Турбаза для Рекламодателей и Брендов: 100% релевантный On-Device таргетинг, рост конверсий в 3–4 раза и честная атрибуция

> **Категория:** [Detailed Overall Impact (Детальный анализ стейкхолдеров)](../README.md)  
> **Идентификатор:** `04_advertisers_presentation` | **Слайдов:** 15 | **Формат:** 16:9 Full HD (1920x1080)  
> **Озвучка:** Edge Neural TTS (`ru-RU-DmitryNeural`, темп `-9%`, тон `-5Hz`) | **Хронометраж:** ~11:30–12:30 мин  
> **Стиль оформления:** Detailed Impact (Неоновая Маджента) (`#e040fb`)

## 🎯 Концепция и ключевая цель

Новая модель рекламы без слежки: локальный On-Device таргетинг (алгоритм идет к данным на устройство, а не данные в облако), кратный рост конверсий за счет абсолютной точности контекста, математическая гарантия отсутствия бот-трафика и честная ZK-атрибуция.

**Целевая аудитория презентации:** Директора по маркетингу (CMO), медиабайеры, бренд-менеджеры, рекламные агентства.

## 🔑 Ключевые архитектурные концепции и технологии

- **On-Device таргетинг:** Рекламные объявления подбираются локальной моделью прямо на смартфоне пользователя с учетом его реальных дел.
- **Рост конверсий в 3–4 раза:** Предложение поступает в идеальный момент контекста задачи без раздражения пользователя.
- **Честная ZK-атрибуция:** Криптографическое подтверждение реального показа живому человеку без раскрытия его профиля рекламодателю.
- **100% ликвидация клик-фрода:** Боты физически не могут сымитировать вызов локального узла с валидным крипто-сертификатом.
- **Снижение стоимости привлечения (CAC):** Исключение гигантской маржи рекламных монополий и оплата строго за подтвержденный контакт.

## 🚀 Просмотр и сборка

### Просмотр через веб-сервер
1. Запустите единый локальный веб-сервер в корне хранилища:
   ```bash
   ./start_presentation.sh
   ```
2. Откройте интерактивную презентацию в браузере:
   ```
   http://localhost:8080/detailed_overall_impact_presentations/04_advertisers_presentation/generated/outputs/web_deck/
   ```
   *(Управление: Пробел / Стрелки — переключение слайдов; Кнопка «Автовоспроизведение» — синхронный показ со звуком).*

### Команды сборки

**Автономная офлайн-сборка (Offline Rebuild, без API-ключа):**
```bash
# Из папки этой презентации:
node rebuild.js

# Из папки категории (detailed_overall_impact_presentations):
npm run rebuild-advertisers

# Из корня хранилища:
npm --prefix detailed_overall_impact_presentations run rebuild-advertisers
```

**Регенерация дикторской речи через Neural TTS (требует API-ключ в корне):**
```bash
# Из папки этой презентации:
node regenerate.js

# Из папки категории (detailed_overall_impact_presentations):
npm run regen-advertisers
```
