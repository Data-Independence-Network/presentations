# Платформа «Турбаза»
## Турбаза для Банков, Финтеха и Операторов Цифрового Рубля: On-Device скоринг, эскроу смарт-контракты и 0% утечек тайны

> **Категория:** [Detailed Overall Impact (Детальный анализ стейкхолдеров)](../README.md)  
> **Идентификатор:** `08_fintech_banking_presentation` | **Слайдов:** 15 | **Формат:** 16:9 Full HD (1920x1080)

## 🎯 Концепция и ключевая цель

Революция в финансовом секторе: кредитный скоринг On-Device (банк получает ZK-доказательство платежеспособности без передачи выписок и транзакций), смарт-контракты эскроу в Цифровом рубле, нулевой риск утечек банковской тайны и мгновенный клиринг B2B сделок.

**Целевая аудитория презентации:** Руководители банков (CIO, CRO), финтех-предприниматели, разработчики платежных решений, регуляторы ЦБ РФ.

## 🔑 Ключевые архитектурные концепции и технологии

- **On-Device кредитный скоринг:** Скоринговая модель банка запускается в изолированном анклаве на телефоне заемщика.
- **0% утечек банковской тайны:** Персональные доходы и траты никогда не передаются на внешние серверы третьих лиц.
- **Программируемый Цифровой рубль:** Автоматическое исполнение условий сделок через безопасные смарт-контракты платформы.
- **Мгновенный P2P-клиринг:** Прямые расчеты между покупателем и продавцом без посредничества зарубежных платежных систем.
- **Снижение резервов на потери:** Сверхточный математический скоринг снижает долю невозвратных кредитов в 2 раза.

## 🚀 Просмотр и сборка

### Просмотр через веб-сервер
1. Запустите единый локальный веб-сервер в корне хранилища:
   ```bash
   ./start_presentation.sh
   ```
2. Откройте интерактивную презентацию в браузере:
   ```
   http://localhost:8080/detailed_overall_impact_presentations/08_fintech_banking_presentation/generated/outputs/web_deck/
   ```
   *(Управление: Пробел / Стрелки — переключение слайдов; Кнопка «Автовоспроизведение» — синхронный показ со звуком).*

### Команды сборки

**Автономная офлайн-сборка (Offline Rebuild, без API-ключа):**
```bash
# Из папки этой презентации:
node rebuild.js

# Из папки категории (detailed_overall_impact_presentations):
npm run rebuild-fintech-banking

# Из корня хранилища:
npm --prefix detailed_overall_impact_presentations run rebuild-fintech-banking
```

**Регенерация дикторской речи через Neural TTS (требует API-ключ в корне):**
```bash
# Из папки этой презентации:
node regenerate.js

# Из папки категории (detailed_overall_impact_presentations):
npm run regen-fintech-banking
```
