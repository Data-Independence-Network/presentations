# Платформа «Турбаза»
## Турбаза для Рекламных Платформ и AdTech: Федеративная дистрибуция, ликвидация клик-фрода и -80% серверных затрат

> **Категория:** [Detailed Overall Impact (Детальный анализ стейкхолдеров)](../README.md)  
> **Идентификатор:** `05_ad_platforms_presentation` | **Слайдов:** 15 | **Формат:** 16:9 Full HD (1920x1080)

## 🎯 Концепция и ключевая цель

Трансформация рекламных сетей: переход от тяжелых централизованных серверов сбора кликстрима к федеративной дистрибуции объявлений, снижение расходов на серверную инфраструктуру на 80%, использование ZK-Proof для верификации и стабильная рентабельность AdTech.

**Целевая аудитория презентации:** Руководители AdTech-компаний, технические директора рекламных сетей, разработчики DSP/SSP платформ.

## 🔑 Ключевые архитектурные концепции и технологии

- **Федеративная дистрибуция объявлений:** Районные Ветки кешируют пакеты объявлений, раздавая их клиентам за доли миллисекунды.
- **-80% затрат на серверный стек:** Отсутствие необходимости хранить и обрабатывать петабайты сырых пользовательских логов.
- **ZK-Proofs вместо следящих Cookies:** Отказ от отслеживания сторонними cookie-файлами в пользу доказательств с нулевым разглашением.
- **Автоматический клиринг роялти:** AdTech-платформа получает фиксированную справедливую комиссию за инфраструктурную доставку креативов.
- **Устойчивость к блокировкам:** Федеративная сеть не может быть выключена блокировкой центральных доменов показа рекламы.

## 🚀 Просмотр и сборка

### Просмотр через веб-сервер
1. Запустите единый локальный веб-сервер в корне хранилища:
   ```bash
   ./start_presentation.sh
   ```
2. Откройте интерактивную презентацию в браузере:
   ```
   http://localhost:8080/detailed_overall_impact_presentations/05_ad_platforms_presentation/generated/outputs/web_deck/
   ```
   *(Управление: Пробел / Стрелки — переключение слайдов; Кнопка «Автовоспроизведение» — синхронный показ со звуком).*

### Команды сборки

**Автономная офлайн-сборка (Offline Rebuild, без API-ключа):**
```bash
# Из папки этой презентации:
node rebuild.js

# Из папки категории (detailed_overall_impact_presentations):
npm run rebuild-ad-platforms

# Из корня хранилища:
npm --prefix detailed_overall_impact_presentations run rebuild-ad-platforms
```

**Регенерация дикторской речи через Neural TTS (требует API-ключ в корне):**
```bash
# Из папки этой презентации:
node regenerate.js

# Из папки категории (detailed_overall_impact_presentations):
npm run regen-ad-platforms
```
