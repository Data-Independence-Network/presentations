## 🎯 Концепция и ключевая цель

Обоснование исторической необходимости перехода от централизованных облачных мега-ЦОД и баз-мишеней к суверенному периферийному расчету (Edge Computing). Презентация демонстрирует моральный и инженерный инвариант отделения программного обеспечения от данных, защиту личной информации семьи в автономных хранилищах и живучесть локального контура при любых внешних потрясениях.

**Целевая аудитория презентации:** Широкая аудитория, руководители министерств и ведомств, инвесторы, ИТ-директора, предприниматели и граждане.

## 🔑 Ключевые архитектурные концепции и технологии

- **Автономные хранилища (%Repository, AIR):** Неприкосновенный реляционный сейф гражданина и семьи на локальном кремнии.
- **Отделение софта от данных:** Преодоление вендор-локина — приложения сменяются свободно, сохраняя единую историю в SQLite.
- **Первичный субъект (%Family):** Защита семейной тайны, совместные дела и поручения без внешней слежки корпораций.
- **Автономный Mesh-контур (%Mesh, %DisasterRecovery):** Работоспособность жизненных сервисов по Bluetooth/Direct Wi-Fi при полном блэкауте интернета.
- **Макроэкономический эффект:** Снижение TCO ЦОД на 87.5%, локализация 85% трафика на уровне района и нулевые утечки ПДн (152-ФЗ Zero-PII).

## 🚀 Просмотр и сборка

### Просмотр через веб-сервер
1. Запустите единый локальный веб-сервер в корне хранилища:
   ```bash
   ./start_presentation.sh
   ```
2. Откройте интерактивную презентацию в браузере:
   ```
   http://localhost:8080/platform_overview/01_paradigm_shift_presentation/generated/outputs/web_deck/
   ```
   *(Управление: Пробел / Стрелки — переключение слайдов; Кнопка «Автовоспроизведение» — синхронный показ со звуком).*

### Команды сборки

**Автономная офлайн-сборка (Offline Rebuild, без API-ключа):**
```bash
# Из папки этой презентации:
node rebuild.js

# Из папки категории (platform_overview):
npm run rebuild-01

# Из корня хранилища:
npm --prefix platform_overview run rebuild-01
```

**Регенерация дикторской речи через Neural TTS (требует API-ключ в корне):**
```bash
# Из папки этой презентации:
node regenerate.js

# Из папки категории (platform_overview):
npm run regen-01
```
