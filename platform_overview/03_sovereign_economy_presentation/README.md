## 🎯 Концепция и ключевая цель

Обоснование новой экономической парадигмы цифровой среды: ликвидация 30%-го платформенного налога магазинов приложений, внедрение экономики совместного использования API со справедливым распределением микророялти 1/N, интеграция смарт-контрактов Цифрового рубля и перенос вычислений искусственного интеллекта на клиентские устройства (Edge AI).

**Целевая аудитория презентации:** Экономисты, регуляторы, финтех-специалисты, венчурные фонды, продуктовые лидеры и разработчики.

## 🔑 Ключевые архитектурные концепции и технологии

- **Экономика API (1/N):** Автоматическое пропорциональное начисление вознаграждения разработчикам библиотек и сервисов в стеке вызова.
- **Интеграция Цифрового рубля ЦБ РФ:** Безопасные смарт-контракты, эскроу-расчеты за товары и услуги без эквайринговых поборов.
- **Edge AI и локальные LLM:** Выполнение нейросетевых моделей непосредственно на чипах смартфонов и ПК без передачи персональных данных.
- **Открытый Web-of-Trust (сеть «Забота»):** Децентрализованная многомерная репутация без рейтингового авторитаризма.
- **Постквантовая криптозащита (PQC):** Долгосрочная защита капитала и цифрового наследия на 30–50 лет вперед.

## 🚀 Просмотр и сборка

### Просмотр через веб-сервер
1. Запустите единый локальный веб-сервер в корне хранилища:
   ```bash
   ./start_presentation.sh
   ```
2. Откройте интерактивную презентацию в браузере:
   ```
   http://localhost:8080/platform_overview/03_sovereign_economy_presentation/generated/outputs/web_deck/
   ```
   *(Управление: Пробел / Стрелки — переключение слайдов; Кнопка «Автовоспроизведение» — синхронный показ со звуком).*

### Команды сборки

**Автономная офлайн-сборка (Offline Rebuild, без API-ключа):**
```bash
# Из папки этой презентации:
node rebuild.js

# Из папки категории (platform_overview):
npm run rebuild-03

# Из корня хранилища:
npm --prefix platform_overview run rebuild-03
```

**Регенерация дикторской речи через Neural TTS (требует API-ключ в корне):**
```bash
# Из папки этой презентации:
node regenerate.js

# Из папки категории (platform_overview):
npm run regen-03
```
