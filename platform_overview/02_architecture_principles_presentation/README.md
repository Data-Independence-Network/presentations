## 🎯 Концепция и ключевая цель

Детальное раскрытие анатомии трехуровневой топологии платформы «Турбаза» (Лист → Ветка → Родительская Ветвь → Ствол), механизмов реляционных внешних ключей между независимыми хранилищами, концепции Общественных Оболочек (API) и формирования «микоризного» интернета данных без центральных серверов-посредников.

**Целевая аудитория презентации:** Системные архитекторы, технические лидеры, ИТ-инженеры, разработчики распределенных систем.

## 🔑 Ключевые архитектурные концепции и технологии

- **4 ранга узлов:** Лист (Edge-клиент), Ветка (районный шлюз), Родительская Ветвь (регион/ведомство), Ствол (федеральный депозитарий).
- **Трехколоночная модель:** Организация виртуальных хранилищ на общей СУБД через триаду `RepositoryId`, `ActorId`, `RecordId`.
- **Принцип Read-Anywhere, Write-Self:** Читать публичные и разделяемые данные отовсюду, писать — строго в собственное хранилище.
- **Общественные Оболочки (API):** Программные контракты безопасного взаимодействия без доступа к сырым базам.
- **Микориза БРИКС+:** Федеративная транзитная интеграция с суверенными системами дружественных государств без зависимости от западных монополий.

## 🚀 Просмотр и сборка

### Просмотр через веб-сервер
1. Запустите единый локальный веб-сервер в корне хранилища:
   ```bash
   ./start_presentation.sh
   ```
2. Откройте интерактивную презентацию в браузере:
   ```
   http://localhost:8080/platform_overview/02_architecture_principles_presentation/generated/outputs/web_deck/
   ```
   *(Управление: Пробел / Стрелки — переключение слайдов; Кнопка «Автовоспроизведение» — синхронный показ со звуком).*

### Команды сборки

**Автономная офлайн-сборка (Offline Rebuild, без API-ключа):**
```bash
# Из папки этой презентации:
node rebuild.js

# Из папки категории (platform_overview):
npm run rebuild-02

# Из корня хранилища:
npm --prefix platform_overview run rebuild-02
```

**Регенерация дикторской речи через Neural TTS (требует API-ключ в корне):**
```bash
# Из папки этой презентации:
node regenerate.js

# Из папки категории (platform_overview):
npm run regen-02
```
