# Платформа «Турбаза»
## «Деловой»: Интеллектуальный персональный органайзер дел, задач и поручений

> **Категория:** [Applications Suite (Флагманские прикладные сервисы)](../README.md)  
> **Идентификатор:** `03_delovoy_app_presentation` | **Слайдов:** 15 | **Формат:** 16:9 Full HD (1920x1080)  
> **Озвучка:** Edge Neural TTS (`ru-RU-DmitryNeural`, темп `-9%`, тон `-5Hz`) | **Хронометраж:** ~11:30–12:30 мин  
> **Стиль оформления:** Прикладной Сервис (Золотой Янтарь) (`#f59e0b / #fbbf24`)  

---

## 🎯 Концепция и ключевая цель

Демонстрация флагманского персонального и семейного органайзера «Деловой». Показывает, как персональный тайм-менеджмент объединяет гравитационные сферы задач, семейные дела, внешние ключи поручений и локальный SQLite с откликом менее 1 мс, исключая слежку облачных провайдеров.

**Целевая аудитория презентации:** Пользователи, семьи, руководители, организаторы процессов, разработчики мобильных приложений.

## 🔑 Ключевые архитектурные концепции и технологии

- **Матрица Эйзенхауэра 2.0:** Динамическое гравитационное ранжирование задач по срочности, важности и контексту.
- **Алгоритм Serendipity:** Преодоление ступора выбора задачи через умную контекстную подсказку следующего шага.
- **Семейный контур:** Делегирование поручений членам семьи без доступа внешних сервисов к расписанию детей.
- **Локальная скорость SQLite:** Мгновенный отклик интерфейса (< 1 мс) благодаря выполнению всех запросов прямо на устройстве.
- **Внешние ссылки:** Бесшовная связка задач с покупками, опросами «КубГолоса» и путешествиями «УраТура».

## 🚀 Просмотр и сборка

### Просмотр через веб-сервер
1. Запустите единый локальный веб-сервер в корне хранилища:
   ```bash
   ./start_presentation.sh
   ```
2. Откройте интерактивную презентацию в браузере:
   ```
   http://localhost:8080/applications_presentations/03_delovoy_app_presentation/generated/outputs/web_deck/
   ```
   *(Управление: Пробел / Стрелки — переключение слайдов; Кнопка «Автовоспроизведение» — синхронный показ со звуком).*

### Команды сборки

**Автономная офлайн-сборка (Offline Rebuild, без API-ключа):**
```bash
# Из папки этой презентации:
node rebuild.js

# Из папки категории (applications_presentations):
npm run rebuild-03

# Из корня хранилища:
npm --prefix applications_presentations run rebuild-03
```

**Регенерация дикторской речи через Neural TTS (требует API-ключ в корне):**
```bash
# Из папки этой презентации:
node regenerate.js

# Из папки категории (applications_presentations):
npm run regen-03
```
