## 🎯 Концепция и ключевая цель

«Деловой» — клиентский органайзер и среда исполнения, в которой каждое Дело живёт в собственном зашифрованном хранилище, а два самостоятельных рейтинга — открытый социальный и закрытый экономический — встречаются только в точке сделки и только по согласию гражданина:
1. **Одно Дело — одно хранилище на Листе:** изоляция обязательств защищает человека от перекрёстных утечек информации;
2. **Контракт на двух уровнях:** подробности работ (чертежи, сметы, фотоотчёты) остаются на устройствах сторон (второй уровень), а финансовые расчёты ведёт Банк России (первый уровень);
3. **Связка двух рейтингов:** открытый социальный рейтинг вкладов по темам из «КубГолоса» и «Заботы» обогащает экономическое решение, но денежный капитал не даёт преимуществ при решении общественных вопросов.

**Целевая аудитория презентации:** Граждане, семьи, самозанятые мастера, артели, предприниматели, разработчики модулей и инженеры распределённых систем.

## 🔑 Ключевые архитектурные концепции

- **Одно Дело — одно хранилище:** Автономный криптографический контур каждого проекта на Листе.
- **Двухуровневый контракт:** Разделение предметной плоскости на смартфонах и регуляторных расчётов Банка России.
- **Независимость рейтингов:** Открытый социальный рейтинг вкладов и закрытый реестр исполнения обязательств не смешиваются.
- **Мандатный шлюз поручений:** Входящие задачи от внешних сервисов попадают в буфер согласования со строгими квотами.
- **Личный слой:** Матрица важности и срочности, экспоненциальное угасание просроченных дел и «Случайный шаг».
- **Безопасная композиция кода:** Трёхзвенная верификация (автоматическая, модельная, встречная) и допуск районной Веткой.

## 🚀 Просмотр и сборка

### Просмотр через веб-сервер
1. Запустите единый локальный веб-сервер в корне репозитория:
   ```bash
   ./start_presentation.sh
   ```
2. Откройте интерактивную презентацию в браузере:
   ```
   http://localhost:8080/applications_presentations/03_delovoy_app_presentation/generated/outputs/web_deck/
   ```
   *(Управление: Пробел / Стрелки — переключение слайдов; Кнопка «Автовоспроизведение» — синхронный показ со звуком).*

### Команды сборки

**Автономная офлайн-сборка (без API-ключа):**
```bash
# Из папки этой презентации:
node rebuild.js

# Из папки категории (applications_presentations):
npm run rebuild-03

# Из корня репозитория:
npm --prefix applications_presentations run rebuild-03
```

**Регенерация дикторской речи через Neural TTS (требует API-ключ в корне):**
```bash
# Из папки этой презентации:
node regenerate.js

# Из папки категории (applications_presentations):
npm run regen-03
```

**Проверка стандартов и инварианта нулевого переполнения:**
```bash
node scripts/check_decks.js applications_presentations/03_delovoy_app_presentation
```
