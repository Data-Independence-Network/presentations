## 🎯 Концепция и ключевая цель

Показ сквозной экономической синергии всех 5 приложений экосистемы: каталог местных мастеров и локальных предприятий шаговой доступности, расчеты по смарт-контрактам Цифрового рубля с эскроу-защитой, нулевые комиссии монополий и мгновенный поиск услуг шаговой доступности.

**Целевая аудитория презентации:** Малый и микробизнес, самозанятые, управляющие компании ЖКХ, муниципальные власти, потребители.

## 🔑 Ключевые архитектурные концепции и технологии

- **Мастера шаговой доступности:** Поиск сантехников, электриков, репетиторов и пекарен за 2 мс через районную Ветку.
- **Ликвидация платформенной дани:** Отсутствие 25–35% комиссий агрегаторов — прямая выгода и заказчику, и мастеру.
- **Смарт-контракты и Эскроу:** Заморозка оплаты в Цифровом рубле и выплата мастеру только по факту подписания акта заказчиком.
- **Репутационный фильтр «Заботы»:** Невозможность фейковых отзывов — рекомендации только от реальных соседей по дому.
- **Полный замкнутый цикл:** Задачи из «Делового» порождают заказы в реестре, опросы в «КубГолосе» и доверие в «Заботе».

## 🚀 Просмотр и сборка

### Просмотр через веб-сервер
1. Запустите единый локальный веб-сервер в корне хранилища:
   ```bash
   ./start_presentation.sh
   ```
2. Откройте интерактивную презентацию в браузере:
   ```
   http://localhost:8080/applications_presentations/05_local_services_presentation/generated/outputs/web_deck/
   ```
   *(Управление: Пробел / Стрелки — переключение слайдов; Кнопка «Автовоспроизведение» — синхронный показ со звуком).*

### Команды сборки

**Автономная офлайн-сборка (Offline Rebuild, без API-ключа):**
```bash
# Из папки этой презентации:
node rebuild.js

# Из папки категории (applications_presentations):
npm run rebuild-05

# Из корня хранилища:
npm --prefix applications_presentations run rebuild-05
```

**Регенерация дикторской речи через Neural TTS (требует API-ключ в корне):**
```bash
# Из папки этой презентации:
node regenerate.js

# Из папки категории (applications_presentations):
npm run regen-05
```
