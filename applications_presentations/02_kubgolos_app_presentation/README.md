## 🎯 Концепция и ключевая цель

Раскрытие архитектуры децентрализованной социологической платформы «КубГолос». Показывает, как принимать качественные коллективные решения снизу вверх через 6 граней куба голосования, ветвящиеся деревья вопросов (%Tree), многокритериальную оценку и защиту от накруток ботами без единой централизованной базы.

**Целевая аудитория презентации:** Муниципальные служащие, социологи, урбанисты, активисты ТСЖ/ЖКХ, продуктовые аналитики.

## 🔑 Ключевые архитектурные концепции и технологии

- **6 граней куба голосования:** Оценка каждого вопроса по 3 факторам (вероятность, желательность, готовность действовать).
- **Древовидное версионирование (%Tree):** Возможность любого участника создать конструктивное уточняющее поддерево опроса.
- **0% ботов и накруток:** Криптографическая привязка голосов к проверенным узлам «Лист» и открытым поручительствам «Заботы».
- **Децентрализованная ZK-агрегация:** Подсчет результатов на районных Ветках с сохранением тайны волеизъявления гражданина.
- **Связка с ЖКХ и МСП:** Прямое принятие решений жильцами домов, дворов и муниципалитетов по реальным проблемам.

## 🚀 Просмотр и сборка

### Просмотр через веб-сервер
1. Запустите единый локальный веб-сервер в корне хранилища:
   ```bash
   ./start_presentation.sh
   ```
2. Откройте интерактивную презентацию в браузере:
   ```
   http://localhost:8080/applications_presentations/02_kubgolos_app_presentation/generated/outputs/web_deck/
   ```
   *(Управление: Пробел / Стрелки — переключение слайдов; Кнопка «Автовоспроизведение» — синхронный показ со звуком).*

### Команды сборки

**Автономная офлайн-сборка (Offline Rebuild, без API-ключа):**
```bash
# Из папки этой презентации:
node rebuild.js

# Из папки категории (applications_presentations):
npm run rebuild-02

# Из корня хранилища:
npm --prefix applications_presentations run rebuild-02
```

**Регенерация дикторской речи через Neural TTS (требует API-ключ в корне):**
```bash
# Из папки этой презентации:
node regenerate.js

# Из папки категории (applications_presentations):
npm run regen-02
```
