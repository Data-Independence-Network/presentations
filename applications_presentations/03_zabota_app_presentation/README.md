# Платформа «Турбаза»
## «Забота»: Социальная сеть взаимной поддержки граждан и открытый репутационный стандарт

> **Категория:** [Applications Suite (Флагманские прикладные сервисы)](../README.md)  
> **Идентификатор:** `03_zabota_app_presentation` | **Слайдов:** 15 | **Формат:** 16:9 Full HD (1920x1080)  
> **Озвучка:** Edge Neural TTS (`ru-RU-DmitryNeural`, темп `-9%`, тон `-5Hz`) | **Хронометраж:** ~11:30–12:30 мин

## 🎯 Концепция и ключевая цель

Презентация доверенной сети взаимной поддержки «Забота». Раскрывает концепцию добрососедства, очных QR-поручительств соседей, переиспользуемых открытых схем репутации и формирования децентрализованного Web-of-Trust без манипулятивного социального рейтинга.

**Целевая аудитория презентации:** Социальные работники, координаторы волонтерских движений, советы домов, разработчики репутационных систем.

## 🔑 Ключевые архитектурные концепции и технологии

- **Доверенное добрососедство:** Помощь пожилым людям, молодым родителям и соседям в радиусе подъезда и дома.
- **Очные поручительства (In-Person QR):** Формирование криптографических цепочек доверия при личной встрече.
- **Многомерный Web-of-Trust:** Репутация строится на реальных подтвержденных делах, а не на лайках и накрутках.
- **Переиспользуемые репутационные схемы:** Любой форум, клуб или маркетплейс может использовать схему доверия «Заботы».
- **Герметичные контуры сообществ:** Закрытые группы жильцов, дворовых комитетов и землячеств без доступа рекламодателей.

## 🚀 Просмотр и сборка

### Просмотр через веб-сервер
1. Запустите единый локальный веб-сервер в корне хранилища:
   ```bash
   ./start_presentation.sh
   ```
2. Откройте интерактивную презентацию в браузере:
   ```
   http://localhost:8080/applications_presentations/03_zabota_app_presentation/generated/outputs/web_deck/
   ```
   *(Управление: Пробел / Стрелки — переключение слайдов; Кнопка «Автовоспроизведение» — синхронный показ со звуком).*

### Команды сборки

**Автономная офлайн-сборка (Offline Rebuild, без API-ключа):**
```bash
# Из папки этой презентации:
node rebuild.js

# Из папки категории (applications_presentations):
npm run rebuild-03

# Из корня хранилища:
npm --prefix applications_presentations run rebuild-03
```

**Регенерация дикторской речи через Neural TTS (требует API-ключ в корне):**
```bash
# Из папки этой презентации:
node regenerate.js

# Из папки категории (applications_presentations):
npm run regen-03
```
