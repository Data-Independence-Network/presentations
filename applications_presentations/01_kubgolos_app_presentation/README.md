## 🎯 Концепция и ключевая цель

«КубГолос» — прикладное приложение, на котором платформа «Турбаза» отрабатывает три базовых архитектурных принципа:
1. **Форму оценки с ограниченным бюджетом влияния (100 базисных пунктов)** и разделением значимости фактора и позиции мнения;
2. **Счётчики в оперативной памяти Ветки** с периодической фиксацией компактных блоков эпох;
3. **Сложение сумм и числа участников вверх по дереву** вместо искажающего усреднения средних.

**Целевая аудитория презентации:** Граждане, социологи, урбанисты, активисты ТСЖ и жилищных кооперативов, муниципальные служащие, инженеры распределённых систем.

## 🔑 Ключевые архитектурные концепции

- **100 базисных пунктов:** Ограниченный бюджет влияния устраняет девальвацию оценок.
- **Две метрики:** Значимость фактора (внимание) и позиция (за/против) выявляют скрытые конфликты.
- **Пиши только своё:** Запись принадлежит автору и защищена его личным ключом; чужие узлы изменить её не могут.
- **Слепой ретранслятор:** Частные опросы не индексируются и считаются только на устройствах участников.
- **Подписанный блок отсечки:** Фиксация результатов голосования по стандарту ГОСТ для внешних реестров.
- **Предел защиты:** Без централизованного удостоверения накрутки нельзя устранить полностью (Дусер, 2002); система последовательно снижает их экономическую выгоду.

## 🚀 Просмотр и сборка

### Просмотр через веб-сервер
1. Запустите единый локальный веб-сервер в корне хранилища:
   ```bash
   ./start_presentation.sh
   ```
2. Откройте интерактивную презентацию в браузере:
   ```
   http://localhost:8080/applications_presentations/01_kubgolos_app_presentation/generated/outputs/web_deck/
   ```

### Команды сборки и проверки

```bash
# Проверка правил оформления, объёма и переполнения:
npm --prefix applications_presentations run check-01
node scripts/check_decks.js applications_presentations/01_kubgolos_app_presentation

# Сборка веб-колоды (без синтеза звука):
node scripts/build_deck_html.js applications_presentations/01_kubgolos_app_presentation
```
