# Платформа «Турбаза»
## «УраТур»: Автономный туристический планер и путеводитель по стране и миру

> **Категория:** [Applications Suite (Флагманские прикладные сервисы)](../README.md)  
> **Идентификатор:** `04_uratur_app_presentation` | **Слайдов:** 15 | **Формат:** 16:9 Full HD (1920x1080)  
> **Озвучка:** Edge Neural TTS (`ru-RU-DmitryNeural`, темп `-9%`, тон `-5Hz`) | **Хронометраж:** ~11:30–12:30 мин  
> **Стиль оформления:** Прикладной Сервис (Пурпурный Аметист) (`#a855f7 / #e879f9`)  

---

## 🎯 Концепция и ключевая цель

Демонстрация туристического планера «УраТур», рожденного из синергии базовых приложений: сборы от «Делового», народные тропы от «КубГолоса» и проверенные проводники от «Заботы». Сервис функционирует на 100% офлайн в горах, тайге и заповедниках по локальной базе SQLite и Mesh-сетям BLE.

**Целевая аудитория презентации:** Туристы, путешественники, туроператоры, гиды, МЧС, региональные комитеты по туризму.

## 🔑 Ключевые архитектурные концепции и технологии

- **Тройная прикладная синергия:** Автоматическая интеграция чек-листов снаряжения, народных рейтингов троп и базы гидов.
- **100% автономность в глуши:** Карты, описания маршрутов и путеводитель хранятся на Листе и не требуют сотовой связи.
- **Локальный Mesh-маяк:** Обмен статусами безопасности и координатами между смартфонами группы через Bluetooth/BLE.
- **Прямые расчеты с гидами:** Оплата услуг инструкторов и бронирование стоянок через Цифровой рубль без посредников.
- **Народный реестр достопримечательностей:** Версионные описания родников, троп и укрытий, обновляемые самими туристами.

## 🚀 Просмотр и сборка

### Просмотр через веб-сервер
1. Запустите единый локальный веб-сервер в корне хранилища:
   ```bash
   ./start_presentation.sh
   ```
2. Откройте интерактивную презентацию в браузере:
   ```
   http://localhost:8080/applications_presentations/04_uratur_app_presentation/generated/outputs/web_deck/
   ```
   *(Управление: Пробел / Стрелки — переключение слайдов; Кнопка «Автовоспроизведение» — синхронный показ со звуком).*

### Команды сборки

**Автономная офлайн-сборка (Offline Rebuild, без API-ключа):**
```bash
# Из папки этой презентации:
node rebuild.js

# Из папки категории (applications_presentations):
npm run rebuild-04

# Из корня хранилища:
npm --prefix applications_presentations run rebuild-04
```

**Регенерация дикторской речи через Neural TTS (требует API-ключ в корне):**
```bash
# Из папки этой презентации:
node regenerate.js

# Из папки категории (applications_presentations):
npm run regen-04
```
