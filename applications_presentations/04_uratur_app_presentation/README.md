## 🎯 Концепция и ключевая цель

«УраТур» — прикладной краеведческий навигатор и планер путешествий, завершающий фундаментальный прикладной квартет платформы («КубГолос», «Забота», «Деловой», «УраТур»). Сервис решает ключевую дилемму современного цифрового туризма: как предоставить семье богатые описания троп, расчёт графиков и навигацию на местности, гарантируя при этом, что личные координаты, маршруты и состав семьи физически остаются на смартфонах путешественников и никогда не передаются на внешние серверы.

**Целевая аудитория презентации:** Семьи с детьми, туристы, краеведы, школьные и детсадовские группы, инструкторы и гиды, природоохранные сообщества (ТОС), муниципалитеты и регуляторы.

## 🔑 Ключевые архитектурные концепции и технологии

- **Возрастной допуск на уровне ядра:** Автоматический отбор записей локальной базой данных Листа без раскрытия личного профиля наружу.
- **Кооперативные теги и индексы:** Распределённый реестр связей на домашних компьютерах туристических клубов и краеведов без централизованных серверов.
- **Прыжковое пересечение тегов:** Алгоритм быстрого поиска по инвертированным спискам, снижающий сетевой трафик в тысячи раз.
- **Автономный хронометраж и безопасность:** Бортовой расчёт скорости по рельефу, коридоров безопасности и времени захода солнца.
- **Двухконтурное разделение маршрута:** Автомобильный подъезд к тропе по внешним картам при 100% изоляции пешеходных семейных треков на Листе.
- **Вывод решений в ядро платформы:** Модули допуска, тегов, геостатистики и планов стандартизируются для всех приложений экосистемы.

## 🚀 Просмотр и сборка

### Просмотр через веб-сервер
1. Запустите единый локальный веб-сервер в корне хранилища:
   ```bash
   ./start_presentation.sh
   ```
2. Откройте интерактивную презентацию в браузере:
   ```
   http://localhost:8080/applications_presentations/04_uratur_app_presentation/generated/outputs/web_deck/
   ```

### Команды проверки и сборки

**Проверка стандартов колоды (текст, тайминги, верстка, переполнения):**
```bash
node scripts/check_decks.js applications_presentations/04_uratur_app_presentation --profile=applications
```

**Автономная офлайн-сборка (с имеющимися мастер-аудио):**
```bash
npm --prefix applications_presentations run rebuild-04
```

**Генерация дикторской озвучки через Neural TTS:**
```bash
npm --prefix applications_presentations run regen-04
```
