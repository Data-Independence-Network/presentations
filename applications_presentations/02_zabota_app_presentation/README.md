## 🎯 Концепция и ключевая цель

«Забота» заменяет поток сообщений вкладами (идеями, опытом, вопросами), хранит их в самозапечатывающихся страницах, которые не разрастаются, и строит из подтверждённых дел открытый социальный рейтинг по темам:
1. **Вклады вместо сообщений:** структурированные обращения вокруг конкретных Случаев вместо смываемой ленты чата;
2. **Запечатанные страницы:** масштабирование связей «один ко многим» без перегрузки журнала и конфликтов одновременной записи;
3. **Открытый социальный рейтинг по темам:** авторитет человека формируется раздельно в каждой теме делом, а единый общий балл не ведётся.

**Целевая аудитория презентации:** Социальные работники, координаторы соседских сообществ, советы домов, инженеры распределённых систем и разработчики платформ взаимной помощи.

## 🔑 Ключевые архитектурные концепции

- **Составная конструкция данных:** Разделение Ситуации, Случая и Разговора исключает монополизацию платформенных сервисов.
- **Самозапечатывающиеся страницы:** Платформенный примитив масштабирования неограниченных коллекций с чтением без сети.
- **Взвешивание мнений по доверию в теме:** Параллельное сопоставление равенства голосов жителей и сублинейного веса экспертов.
- **Язык субъективной логики и затухание:** Математический аппарат работы с неполными данными и естественное старение свидетельств.
- **Защита от самоусиления:** Комплекс институциональных и криптографических барьеров против сговоров и автокаталитических накруток.
- **Независимость социального и экономического рейтингов:** Репутация взаимопомощи отделена от закрытых финансовых расчётов.

## 🚀 Просмотр и сборка

### Просмотр через веб-сервер
1. Запустите единый локальный веб-сервер в корне хранилища:
   ```bash
   ./start_presentation.sh
   ```
2. Откройте интерактивную презентацию в браузере:
   ```
   http://localhost:8080/applications_presentations/02_zabota_app_presentation/generated/outputs/web_deck/
   ```

### Команды сборки
**Автономная офлайн-сборка (без API-ключа):**
```bash
npm --prefix applications_presentations run rebuild-02
```

**Регенерация дикторской речи через Neural TTS (требует API-ключ в корне):**
```bash
npm --prefix applications_presentations run regen-02
```
