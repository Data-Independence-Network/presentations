# Дизайн-системы и шаблоны слайдов (Shared Templates)

## Обзор директории `shared_templates/`

Данная директория содержит эталонные архитектурные шаблоны и заготовки презентационных движков:
- **`overview_presentation_deck/`**: Эталонная темная билборд-тема («Dark Sovereign») для стратегических мастер-презентаций.
- **`platform_overview_deck/`**: Шаблон для базового концептуального эксплейнера.

---

## 🔒 Принцип строгой изоляции стилей (Strict Style Isolation)

Согласно правилам репозитория:
1. **Шаблоны служат исключительно образцом:** Файлы в `shared_templates/` используются как библиотека шаблонов при создании новых презентаций.
2. **Запрет runtime-импортов:** Презентации ни при каких обстоятельствах не импортируют и не линкуют стили напрямую из `shared_templates/`.
3. **Автономность каждой презентации:** Каждая презентация владеет собственной изолированной копией таблицы стилей в папке `docs/deck.css`, что гарантирует полное отсутствие регрессий при любых доработках.
