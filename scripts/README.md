# Глобальный движок сборки презентаций и медиа-пайплайнов (Scripts)

## Назначение директории `scripts/`
Директория содержит глобальные скрипты автоматизации, CLI-утилиты и ядро сборочного конвейера платформы «Турбаза».

---

## 🧭 Архитектура конвейера
```
scripts/
├── core/
│   ├── incremental_engine.js     # Инкрементальный сборщик на базе SHA-256 хешей и Git чекпоинтов
│   ├── deck_builder.js           # Компилятор интерактивного HTML5 веб-плеера из presentation_deck.md
│   ├── utils.js                  # Фонетические замены, замеры длительности аудио, вставка пауз
│   ├── tts_generator.js          # Синтез речи через Microsoft Edge Neural TTS (ru-RU-DmitryNeural)
│   ├── slide_capture.js          # Снятие скриншотов слайдов 1920x1080 через Playwright
│   ├── handout_pdf_builder.js    # Генерация раздаточных заметок A4 (слайд + дикторский текст)
│   ├── slides_pdf_builder.js     # Чистый альбомный 16:9 PDF комплект слайдов
│   ├── whitepaper_pdf_builder.js # Сборщик Белых Книг и аналитических отчетов из Markdown
│   └── video_builder.js          # Рендеринг видеороликов через FFmpeg (email, 10mb, master)
│
├── rebuild.js                    # Офлайн пересборщик (без интернета, на базе зафиксированного аудио)
├── regenerate.js                 # Умный инкрементальный регенератор (с синтезом новой речи)
└── build_all.js                  # Запуск полного сборочного цикла для всех презентаций
```

---

## 🚀 Основные команды запуска
```bash
# Офлайн сборка всех презентаций:
npm run rebuild-all

# Полная регенерация всех презентаций (требует API ключ):
npm run regenerate-all

# Сборка всех Белых Книг (Whitepapers PDF):
npm run build-whitepapers
```
