## 🎯 Концепция и ключевая цель

Подробное описание архитектуры промежуточного узла «Ветка»: трехстадийный конвейер обработки данных (PersistentQueue → ConcurrentMap → FileSystem), временные путешествия (Time-Traveling), усечение устаревших версий (Pruning), разграничение горячего и холодного хранения, и локализация сетевого трафика.

**Целевая аудитория презентации:** Бэкенд-инженеры, архитекторы высоконагруженных систем, специалисты по надежности (SRE).

## 🔑 Ключевые архитектурные концепции и технологии

- **Трехстадийный конвейер Ветки:** Очередь `PersistentQueue` $\to$ оперативная память `ConcurrentMap` $\to$ файловое хранилище `FileSystem`.
- **Time-Traveling (Временные путешествия):** Возможность воспроизвести точное состояние реестров на любой исторический момент времени.
- **Интеллектуальный Pruning:** Автоматическая очистка промежуточных диффов и усечение логов без нарушения криптографической целостности.
- **Hot & Cold Sync:** Мгновенный обмен оперативными обновлениями и фоновая архивация тяжелых мультимедиа-блоков.
- **Районный шлюз к госсистемам:** Изолированные коннекторы к ЕСИА, СБП и ГИС ЖКХ на уровне муниципальной Ветки.

## 🚀 Просмотр и сборка

### Просмотр через веб-сервер
1. Запустите единый локальный веб-сервер в корне хранилища:
   ```bash
   ./start_presentation.sh
   ```
2. Откройте интерактивную презентацию в браузере:
   ```
   http://localhost:8080/architecture_presentations/04_branch_pipeline_and_storage/generated/outputs/web_deck/
   ```
   *(Управление: Пробел / Стрелки — переключение слайдов; Кнопка «Автовоспроизведение» — синхронный показ со звуком).*

### Команды сборки

**Автономная офлайн-сборка (Offline Rebuild, без API-ключа):**
```bash
# Из папки этой презентации:
node rebuild.js

# Из папки категории (architecture_presentations):
npm run rebuild-04

# Из корня хранилища:
npm --prefix architecture_presentations run rebuild-04
```

**Регенерация дикторской речи через Neural TTS (требует API-ключ в корне):**
```bash
# Из папки этой презентации:
node regenerate.js

# Из папки категории (architecture_presentations):
npm run regen-04
```
