## 🎯 Концепция и ключевая цель

Анализ внутреннего устройства узла «Лист»: использование единой встраиваемой реляционной СУБД SQLite в режиме WAL, модель виртуальных хранилищ (микро-блокчейнов), трехколоночный составной первичный ключ (RepositoryId, ActorId, RecordId), мостовые сущности (Bridge Entities) и математические гарантии Anti-Linkability.

**Целевая аудитория презентации:** Инженеры баз данных, системные программисты, разработчики клиентского ПО, специалисты по информационной безопасности.

## 🔑 Ключевые архитектурные концепции и технологии

- **Встраиваемый SQLite в режиме WAL:** Высокопроизводительный движок с конкурентным чтением и ACID-транзакциями.
- **Виртуальные хранилища как микро-блокчейны:** Множество логических изолированных хранилищ живут внутри единой базы клиента, каждое со своим детерминированным журналом изменений (TransactionLog).
- **Трехколоночный идентификатор:** `RepositoryId` + `ActorId` + `RecordId` образуют универсальный составной первичный ключ.
- **Мостовые сущности (Bridge Entities):** Децентрализованная реализация связей M:N между независимыми таблицами без единого владельца.
- **Anti-Linkability и eGUID:** Эфемерные идентификаторы, исключающие возможность сквозного профилирования пользователя.

## 🚀 Просмотр и сборка

### Просмотр через веб-сервер
1. Запустите единый локальный веб-сервер в корне хранилища:
   ```bash
   ./start_presentation.sh
   ```
2. Откройте интерактивную презентацию в браузере:
   ```
   http://localhost:8080/architecture_presentations/02_leaf_storage_engine/generated/outputs/web_deck/
   ```
   *(Управление: Пробел / Стрелки — переключение слайдов; Кнопка «Автовоспроизведение» — синхронный показ со звуком).*

### Команды сборки

**Автономная офлайн-сборка (Offline Rebuild, без API-ключа):**
```bash
# Из папки этой презентации:
node rebuild.js

# Из папки категории (architecture_presentations):
npm run rebuild-02

# Из корня хранилища:
npm --prefix architecture_presentations run rebuild-02
```

**Регенерация дикторской речи через Neural TTS (требует API-ключ в корне):**
```bash
# Из папки этой презентации:
node regenerate.js

# Из папки категории (architecture_presentations):
npm run regen-02
```
