## 🎯 Концепция и ключевая цель

Презентация технологии глобального поиска TreeSearch: многоуровневая индексация по древовидной топологии, конфиденциальный поиск на клиентском устройстве (On-Device Search), дублирование агрегированных метаданных «вверх» для государственной аналитики и протоколы аварийного восстановления (Disaster Recovery).

**Целевая аудитория презентации:** Инженеры поисковых систем, аналитики данных (Big Data), специалисты по Disaster Recovery, системные архитекторы.

## 🔑 Ключевые архитектурные концепции и технологии

- **Алгоритм TreeSearch:** Иерархический поиск от локального узла к Ветке и Стволу с отсечением нерелевантных ветвей графа.
- **On-Device приватный поиск:** Полнотекстовый поиск по личным данным без передачи поисковых запросов в облако.
- **Федеративная аналитика без раскрытия ПДн:** Государство и бизнес получают точные макро-метрики через агрегацию математических доказательств.
- **Дублирование «вверх» для Disaster Recovery:** Криптографически запечатанные резервные копии публичных данных на вышестоящих Ветках.
- **Поисковые фильтры и ранжирование:** Прозрачные алгоритмы ранжирования результатов без скрытой коммерческой манипуляции.

## 🚀 Просмотр и сборка

### Просмотр через веб-сервер
1. Запустите единый локальный веб-сервер в корне хранилища:
   ```bash
   ./start_presentation.sh
   ```
2. Откройте интерактивную презентацию в браузере:
   ```
   http://localhost:8080/architecture_presentations/06_tree_search_and_analytics/generated/outputs/web_deck/
   ```
   *(Управление: Пробел / Стрелки — переключение слайдов; Кнопка «Автовоспроизведение» — синхронный показ со звуком).*

### Команды сборки

**Автономная офлайн-сборка (Offline Rebuild, без API-ключа):**
```bash
# Из папки этой презентации:
node rebuild.js

# Из папки категории (architecture_presentations):
npm run rebuild-06

# Из корня хранилища:
npm --prefix architecture_presentations run rebuild-06
```

**Регенерация дикторской речи через Neural TTS (требует API-ключ в корне):**
```bash
# Из папки этой презентации:
node regenerate.js

# Из папки категории (architecture_presentations):
npm run regen-06
```
