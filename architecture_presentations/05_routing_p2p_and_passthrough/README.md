## 🎯 Концепция и ключевая цель

Разбор сетевого стека платформы: использование хранилищ в качестве асинхронного сигнального сервера для установки WebRTC P2P-соединений, OIDC-аутентификация без централизованных удостоверяющих центров, глобальная синхронизация времени TrueTime и организация сквозных туннелей (PassThroughConnection) к закрытым ведомственным базам.

**Целевая аудитория презентации:** Сетевые инженеры, специалисты по протоколам P2P, криптографы, инженеры безопасности.

## 🔑 Ключевые архитектурные концепции и технологии

- **Асинхронный P2P-сигналинг через хранилища:** Установка прямых P2P-сессий между пирами даже если они не находятся одновременно онлайн.
- **OIDC и децентрализованная идентификация:** Подтверждение полномочий через криптографические токены без внешних серверов авторизации.
- **Сквозные туннели (PassThroughConnection):** Прямые зашифрованные каналы от клиентского Листа к ведомственным реестрам.
- **Синхронизация TrueTime:** Доверенные временные метки для упорядочивания распределенных транзакций без центрального координатора.
- **Обход NAT и STUN/TURN:** Надежное пробитие межсетевых экранов и прямое peer-to-peer соединение между смартфонами.

## 🚀 Просмотр и сборка

### Просмотр через веб-сервер
1. Запустите единый локальный веб-сервер в корне хранилища:
   ```bash
   ./start_presentation.sh
   ```
2. Откройте интерактивную презентацию в браузере:
   ```
   http://localhost:8080/architecture_presentations/05_routing_p2p_and_passthrough/generated/outputs/web_deck/
   ```
   *(Управление: Пробел / Стрелки — переключение слайдов; Кнопка «Автовоспроизведение» — синхронный показ со звуком).*

### Команды сборки

**Автономная офлайн-сборка (Offline Rebuild, без API-ключа):**
```bash
# Из папки этой презентации:
node rebuild.js

# Из папки категории (architecture_presentations):
npm run rebuild-05

# Из корня хранилища:
npm --prefix architecture_presentations run rebuild-05
```

**Регенерация дикторской речи через Neural TTS (требует API-ключ в корне):**
```bash
# Из папки этой презентации:
node regenerate.js

# Из папки категории (architecture_presentations):
npm run regen-05
```
