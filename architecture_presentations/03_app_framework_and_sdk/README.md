## 🎯 Концепция и ключевая цель

Исследование архитектуры прикладного каркаса (Framework) и Turbase SDK. Освещение фундаментального контракта «Read-Anywhere, Write-Self», песочницы безопасности выполнения стороннего кода, декларативных правил доступа (AccessRules), журнала транзакций (TransactionLog) и эволюции схем данных.

**Целевая аудитория презентации:** Разработчики приложений, авторы фреймворков, системные архитекторы, техлиды команд разработки.

## 🔑 Ключевые архитектурные концепции и технологии

- **Принцип Read-Anywhere, Write-Self:** Приложение читает любые разрешенные таблицы, но пишет строго в таблицы своего хранилища.
- **Песочница исполнения (Framework):** Защищенная изолированная среда выполнения логики без прямого доступа к чужой памяти.
- **Декларативные AccessRules:** Строгие мандатные правила доступа к полям и записям на уровне самого движка хранения.
- **Журнал транзакций:** Неизменяемый аудит-лог каждого изменения с криптографической подписью автора.
- **Эволюция схем и миграции:** Механизмы бесшовного обновления структур таблиц без риска потери пользовательских данных.

## 🚀 Просмотр и сборка

### Просмотр через веб-сервер
1. Запустите единый локальный веб-сервер в корне хранилища:
   ```bash
   ./start_presentation.sh
   ```
2. Откройте интерактивную презентацию в браузере:
   ```
   http://localhost:8080/architecture_presentations/03_app_framework_and_sdk/generated/outputs/web_deck/
   ```
   *(Управление: Пробел / Стрелки — переключение слайдов; Кнопка «Автовоспроизведение» — синхронный показ со звуком).*

### Команды сборки

**Автономная офлайн-сборка (Offline Rebuild, без API-ключа):**
```bash
# Из папки этой презентации:
node rebuild.js

# Из папки категории (architecture_presentations):
npm run rebuild-03

# Из корня хранилища:
npm --prefix architecture_presentations run rebuild-03
```

**Регенерация дикторской речи через Neural TTS (требует API-ключ в корне):**
```bash
# Из папки этой презентации:
node regenerate.js

# Из папки категории (architecture_presentations):
npm run regen-03
```
