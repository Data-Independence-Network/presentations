## 🎯 Концепция и ключевая цель

Глубокий технический разбор четырехуровневой древовидной иерархии платформы «Турбаза» (Лист → Ветка → Родительская Ветвь → Ствол), архитектурной философии AIR (Автономные взаимозависимые хранилища), строгого разделения Data Plane и Control Plane, а также протоколов международной интеграции БРИКС/ЕАЭС.

**Целевая аудитория презентации:** Главные архитекторы систем, сетевые инженеры, CTO, разработчики распределенных платформ.

## 🔑 Ключевые архитектурные концепции и технологии

- **Четыре ранга узлов:** Лист (Edge runtime), Ветка (районный шлюз), Родительская Ветвь (регион), Ствол (федеральный контур).
- **Философия AIR (%Repository):** Каждое хранилище автономно, самодостаточно и связано с миром только декларативными ссылками.
- **Разделение плоскостей:** Data Plane герметичен на уровне клиента, Control Plane маршрутизирует транзитные потоки.
- **Partition Tolerance (Устойчивость к изоляции):** Локальные узлы Лист и Ветка сохраняют 100% функциональности при обрыве магистралей.
- **Суверенный шлюз БРИКС (%International):** Стандартизированный транзитный протокол межнационального обмена данными.

## 🚀 Просмотр и сборка

### Просмотр через веб-сервер
1. Запустите единый локальный веб-сервер в корне хранилища:
   ```bash
   ./start_presentation.sh
   ```
2. Откройте интерактивную презентацию в браузере:
   ```
   http://localhost:8080/architecture_presentations/01_topology_and_sovereignty/generated/outputs/web_deck/
   ```
   *(Управление: Пробел / Стрелки — переключение слайдов; Кнопка «Автовоспроизведение» — синхронный показ со звуком).*

### Команды сборки

**Автономная офлайн-сборка (Offline Rebuild, без API-ключа):**
```bash
# Из папки этой презентации:
node rebuild.js

# Из папки категории (architecture_presentations):
npm run rebuild-01

# Из корня хранилища:
npm --prefix architecture_presentations run rebuild-01
```

**Регенерация дикторской речи через Neural TTS (требует API-ключ в корне):**
```bash
# Из папки этой презентации:
node regenerate.js

# Из папки категории (architecture_presentations):
npm run regen-01
```
