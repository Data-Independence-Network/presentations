## 🎯 Концепция и ключевая цель

Финальный выпуск архитектурной серии: глубокий разбор криптографического периметра по стандартам ГОСТ Р 34.12/34.11/34.10, постквантовой криптографии (PQC на решетках), архитектуры связки ключей (Keyring), трейсов выполнения транзакций (Execution Trace), теории игр консенсуса и механики распределения микророялти 1/N.

**Целевая аудитория презентации:** Криптографы, специалисты по информационной безопасности, финтех-архитекторы, регуляторы, ведущие разработчики.

## 🔑 Ключевые архитектурные концепции и технологии

- **152-ФЗ Zero-PII:** Абсолютное соответствие закону о персональных данных благодаря их физическому неудалению с устройства владельца.
- **Отечественный криптоконтур ГОСТ:** Шифрование «Кузнечик» / «Магма», хеширование «Стрибог» и электронная подпись ГОСТ Р 34.10-2012.
- **Постквантовая защита (PQC):** Алгоритмы на решетках (ML-KEM / ML-DSA), гарантирующие стойкость данных на 30–50 лет.
- **Архитектура Keyring и Shamir Recovery:** Разделение мастер-ключа на доли и безопасное социальное восстановление доступа.
- **Экономика API 1/N и консенсус:** Теоретико-игровая модель автоматического расщепления доходов между всеми участниками цепочки вызовов.

## 🚀 Просмотр и сборка

### Просмотр через веб-сервер
1. Запустите единый локальный веб-сервер в корне хранилища:
   ```bash
   ./start_presentation.sh
   ```
2. Откройте интерактивную презентацию в браузере:
   ```
   http://localhost:8080/architecture_presentations/07_cryptography_and_api_economy/generated/outputs/web_deck/
   ```
   *(Управление: Пробел / Стрелки — переключение слайдов; Кнопка «Автовоспроизведение» — синхронный показ со звуком).*

### Команды сборки

**Автономная офлайн-сборка (Offline Rebuild, без API-ключа):**
```bash
# Из папки этой презентации:
node rebuild.js

# Из папки категории (architecture_presentations):
npm run rebuild-07

# Из корня хранилища:
npm --prefix architecture_presentations run rebuild-07
```

**Регенерация дикторской речи через Neural TTS (требует API-ключ в корне):**
```bash
# Из папки этой презентации:
node regenerate.js

# Из папки категории (architecture_presentations):
npm run regen-07
```
