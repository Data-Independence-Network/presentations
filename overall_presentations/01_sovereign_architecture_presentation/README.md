## 🎯 Концепция и ключевая цель

Главная техническая мастер-презентация платформы «Турбаза». Комплексный стратегический обзор трехуровневой топологии (Лист → Ветка → Ствол), ликвидации баз-мишеней (Honeypots), архитектурного принципа 152-ФЗ Zero-PII, работы при полном блэкауте интернета и сопоставления с устаревшими централизованными архитектурами.

**Целевая аудитория презентации:** Высшее руководство, совет директоров, министры цифрового развития, генеральные конструкторы ИТ-систем.

## 🔑 Ключевые архитектурные концепции и технологии

- **Глобальная 3-уровневая топология:** Лист (Edge) $\to$ Ветка (Муниципалитет) $\to$ Ствол (Федеральный депозитарий).
- **Ликвидация баз-мишеней:** Отсутствие централизованных хранилищ персональных данных устраняет сам вектор массовых утечек.
- **Математический инвариант Zero-PII:** На серверах циркулируют только открытые ключи и ZK-доказательства — ноль байт сырых ПДн.
- **Архитектурный чертеж платформы:** Детальная визуализация потоков данных и разграничения контуров ответственности.
- **Сопровождающий документ:** Архитектурный буклет `turbase_presentation_visuals.pdf` с полностраничными диаграммами.

## 🚀 Просмотр и сборка

### Просмотр через веб-сервер
1. Запустите единый локальный веб-сервер в корне хранилища:
   ```bash
   ./start_presentation.sh
   ```
2. Откройте интерактивную презентацию в браузере:
   ```
   http://localhost:8080/overall_presentations/01_sovereign_architecture_presentation/generated/outputs/web_deck/
   ```
   *(Управление: Пробел / Стрелки — переключение слайдов; Кнопка «Автовоспроизведение» — синхронный показ со звуком).*

### Команды сборки

**Автономная офлайн-сборка (Offline Rebuild, без API-ключа):**
```bash
# Из папки этой презентации:
node rebuild.js

# Из папки категории (overall_presentations):
npm run rebuild-architecture

# Из корня хранилища:
npm --prefix overall_presentations run rebuild-architecture
```

**Регенерация дикторской речи через Neural TTS (требует API-ключ в корне):**
```bash
# Из папки этой презентации:
node regenerate.js

# Из папки категории (overall_presentations):
npm run regen-architecture
```
