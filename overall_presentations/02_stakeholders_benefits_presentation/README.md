## 🎯 Концепция и ключевая цель

Главная экономическая мастер-презентация платформы «Турбаза». Развернутая матрица ценности для 6 ключевых групп стейкхолдеров (Граждане, Малый и Средний Бизнес, Рекламодатели и AdTech, Банки и Финтех, Государство и Муниципалитеты, Органы Безопасности), объективный анализ PROs/CONs/Mitigation и сценарии запуска Day-1.

**Целевая аудитория презентации:** Инвесторы, экономисты, руководители отраслей, представители бизнес-ассоциаций, государственные регуляторы.

## 🔑 Ключевые архитектурные концепции и технологии

- **6-секторная матрица ценности:** Системный анализ пользы для всех участников национальной цифровой экосистемы.
- **Честный анализ барьеров (CONs) и компенсаций:** Психологические, технические и правовые ответы на опасения внедрения.
- **Драйвер запуска первого дня (Day-1):** Флагманский стек приложений («Деловой», «КубГолос», «Забота», «УраТур») для органического старта.
- **Игра с положительной суммой (Positive-Sum Game):** Каждый участник выигрывает от подключения других, раскручивая сетевой маховик.
- **Сопровождающий документ:** Полная матрица стейкхолдеров `turbase_stakeholders_value_matrix.pdf` (65 КБ аналитического текста).

## 🚀 Просмотр и сборка

### Просмотр через веб-сервер
1. Запустите единый локальный веб-сервер в корне хранилища:
   ```bash
   ./start_presentation.sh
   ```
2. Откройте интерактивную презентацию в браузере:
   ```
   http://localhost:8080/overall_presentations/02_stakeholders_benefits_presentation/generated/outputs/web_deck/
   ```
   *(Управление: Пробел / Стрелки — переключение слайдов; Кнопка «Автовоспроизведение» — синхронный показ со звуком).*

### Команды сборки

**Автономная офлайн-сборка (Offline Rebuild, без API-ключа):**
```bash
# Из папки этой презентации:
node rebuild.js

# Из папки категории (overall_presentations):
npm run rebuild-stakeholder

# Из корня хранилища:
npm --prefix overall_presentations run rebuild-stakeholder
```

**Регенерация дикторской речи через Neural TTS (требует API-ключ в корне):**
```bash
# Из папки этой презентации:
node regenerate.js

# Из папки категории (overall_presentations):
npm run regen-stakeholder
```
