# Реестр и регламент совместных сессий (Sessions)

Данный каталог предназначен для систематического ведения, протоколирования и архивации всех совместных рабочих сессий оператора проекта (**Артём Владимирович Шамсутдинов**) и языковых моделей (**Gemini 3.8 Flash**, **Claude Sonnet 3.5 / 5.5** и др.).

---

## 🎯 1. Единая точка входа: `Current_Topic_and_process.md`

Главным координирующим документом является файл [`Current_Topic_and_process.md`](file:///Users/parents/Documents/presentations/sessions/Current_Topic_and_process.md).
- В нём зафиксирован **указатель на актуальный файл темы и процесса**.
- Оператор может в любой момент переключить фокус работы, указав путь к новому файлу заметок (например, в каталоге `shared_docs/comments/2026/`) или перечислив несколько тем.
- **Принцип динамической привязки:** модели ни при каких обстоятельствах не зашивают жёстко конкретные имена файлов тем в свои алгоритмы. Они всегда динамически считывают путь из указателя.

---

## 🚀 2. Обязательный протокол первого ответа для моделей

При начале любой новой сессии (на самое первое сообщение оператора) модель **обязана**:
1. Открыть [`Current_Topic_and_process.md`](file:///Users/parents/Documents/presentations/sessions/Current_Topic_and_process.md) и прочитать указанный файл темы.
2. Извлечь из файла темы описанные в нём ступени и этапы процесса.
3. Начать свой первый ответ с вопроса: **«О какой ступени процесса темы будет эта сессия?»** с перечислением доступных ступеней (если указано несколько тем — предложить выбор темы и ступени).
4. Не приступать к выполнению сторонних задач до согласования темы и ступени.
5. Инициализировать файл протокола в каталоге `sessions/2026/` и вести запись хода диалога, рассуждений и промежуточных решений.

## 📁 3. Структура каталогов и именование файлов

```
sessions/
├── Current_Topic_and_process.md     # Указатель на текущую тему, ступени и регламент сессии
├── README.md                        # Настоящее описание архитектуры сессий
├── AGENTS.md                        # Регламент для ИИ-агентов
└── 2026/                            # Хронологический архив протоколов сессий за 2026 год
    ├── 10-05_00_session_format_tempate.md   # Базовый шаблон протоколирования
    └── MM-DD_NN_Name_of_session.md          # Файлы протоколов сессий (дата, номер, тема)
```

### Формат имени файла сессии:
`MM-DD_NN_Name_of_session.md`
- `MM-DD` — месяц и день (например, `10-05` — 5 октября).
- `NN` — порядковый номер сессии за день (`01`, `02`, `03`...).
- `Name_of_session` — краткое понятное описание фокуса сессии.
