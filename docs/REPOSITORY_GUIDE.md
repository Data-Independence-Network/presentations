> [!NOTE]
> **Техническая спецификация инженерной инфраструктуры и сборочных конвейеров**  
> Настоящий документ представляет исчерпывающее техническое руководство по внутреннему устройству Git-репозитория, скриптам сборки, автоматизации экспорта слайдов, синтезу нейроозвучки и ключевым инженерным инвариантам презентационного комплекса и комплекта Белых Книг платформы прямого владения данными «Турбаза».

## 1. Назначение и масштаб комплекса

Репозиторий содержит полный цикл презентационных, аналитических, проектных и инженерных материалов трехуровневой платформы «Турбаза» (Лист $\to$ Ветка $\to$ Ствол):
- **27 интерактивных презентаций** (405 широкоформатных слайдов 16:9);
- **8 полностью завершённых треков (120 слайдов)** со студийной синхронной нейроозвучкой DmitryNeural;
- **2 прикладных трека** в процессе подготовки к согласованию с Белыми Книгами;
- **17 концептуальных инженерных и отраслевых проектов**, открытых для создания практических прототипов;
- **12 аналитических Белых Книг (Whitepapers)** и архитектурный генеральный документ;
- **База авторских заметок разработчика (`shared_docs/comments/`)** и семантический указатель терминов ([LABELS.md](../shared_docs/comments/LABELS.md)).

## 3. Локальный просмотр презентаций (Offline View)

Для локального просмотра всех готовых материалов **не требуется компиляция или установка тяжелых сред разработки**. Все веб-плееры (`web_deck/index.html`) и аудиодорожки нейроозвучки (`.mp3`) уже скомпилированы и зафиксированы в Git.

### 3.1. Системные требования:
- **Python 3** (встроен в macOS и Linux) — для легковесного локального HTTP-сервера;
- **Любой современный браузер** (Safari, Chrome, Chromium, Firefox, Edge).

### 3.2. Команда запуска:
В корне репозитория выполните:
```bash
./start_presentation.sh
```
Скрипт запускает сервер на порту 8080 и открывает страницу:  
👉 **`http://localhost:8080/`** — единая витрина презентационного комплекса.

### 3.3. Управление звуком в браузере:
Из-за политик безопасности современных браузеров (Safari / Chrome), блокирующих автовоспроизведение звука до взаимодействия с пользователем:
- Нажмите кнопку **«🔊 Озвучка» два раза** в верхнем меню (первый клик выдаёт разрешение браузера, второй запускает воспроизведение);
- Либо кликните в любом месте экрана / нажмите клавишу `Пробел`.

## 4. Системные зависимости и скрипты установки

Установочные скрипты требуются только разработчикам, модифицирующим разметку слайдов, генерирующим PDF/видео или перезаписывающим звук:

### 4.1. Базовое окружение сборки (`install_build_dependencies.sh`)
Устанавливает системные пакеты для рендеринга и конвертации:
- `Node.js` (рекомендуется v20+) и `npm`;
- `Playwright` + браузер Chromium Headless (`google-chrome --headless=new`);
- `FFmpeg` и `FFprobe` (для сборки MP4-видео из слайдов и звука);
- Системные шрифты (PT Astra Sans, PT Astra Mono).

Запуск:
```bash
./install_build_dependencies.sh
# или через npm:
npm run install:build
```

### 4.2. Окружение синтеза речи (`install_regen_dependencies.sh`)
Настраивает модуль нейросинтеза русской речи на базе Microsoft Edge Neural TTS:
- Библиотека `node-edge-tts` с дикторским голосом `ru-RU-DmitryNeural` (скорость -9%, высота тона -5Hz);
- Валидация файла `text_to_speech_mcp_Open_API_key.txt` в корне репозитория (файл исключён из Git через `.gitignore`).

Запуск:
```bash
./install_regen_dependencies.sh
# или через npm:
npm run install:regen
```

## 5. Автоматизация и сценарии сборки (NPM Workspaces)

Репозиторий использует модульную систему сборки с SHA-256 хэшированием контента (`generated/.build_cache.json`). Повторные неизмененные слайды и аудиосегменты не пересобираются.

### 5.1. Офлайн-сборка (Offline Rebuild без API-ключей):
Использует уже закоммиченные `.mp3` дорожки и пересобирает веб-деки, PNG-кадры и PDF-раздатки:
```bash
# Базовый обзор платформы (3 презентации):
npm run rebuild-platform-overview

# Флагманские сервисы (5 презентаций):
npm run rebuild-apps

# Инженерная архитектура (7 презентаций):
npm run rebuild-arch

# Мастер-презентации верхнего уровня (2 презентации):
npm run rebuild-overall

# Отраслевой анализ участников экосистемы (10 презентаций):
npm run rebuild-impact

# Все Белые Книги в формат PDF (Whitepapers):
npm run build-whitepapers

# Полная сквозная сборка абсолютно всех презентаций комплекса:
npm run rebuild-all
```

### 5.2. Регенерация с синтезом нового звука (Neural TTS):
Применяется при изменении дикторского текста в `docs/presentation_deck.md` (требует API-ключ в корне):
```bash
npm run regen-platform-overview
npm run regen-apps
npm run regen-arch
npm run regen-overall
npm run regen-impact
npm run regenerate-all
```

### 5.3. Автоматическая верификация разметки (Проверка качества):
```bash
# Полная проверка всех 27 презентаций на переполнение (Zero-Overflow в браузере):
npm run check-decks

# Быстрая текстовая верификация без запуска браузера:
node scripts/check_decks.js platform_overview/01_paradigm_shift_presentation --no-browser
```

## 6. Ключевые архитектурные и инженерные инварианты

1. **Двухслойная архитектура стилей (Two-Layer Presentation Architecture):**
   - **Слой 1: Универсальный хром-движок ([shared_templates/deck_core/css/deck_core.css](../shared_templates/deck_core/css/deck_core.css)):** Внешняя оболочка плеера (контейнер 16:9, верхняя панель, кнопки навигации, переключатель звука, модальная сетка слайдов) централизована. Обновление элементов управления применяется сразу ко всем презентациям без дублирования кода.
   - **Слой 2: 100% изолированный холст слайда (`docs/deck.css` в каждой презентации):** Стили карточек, сетки, диаграммы Mermaid и цветовые переменные замкнуты внутри каждой презентации. Правка верстки в одной презентации физически не может повлиять на остальные 26 презентаций.
2. **Инвариант нулевого переполнения (Zero-Overflow Invariant):**
   - Все 405 слайдов оптимизированы под фиксированный холст 1920x1080.
   - Не допускается появление полос вертикальной или горизонтальной прокрутки (`scrollHeight <= clientHeight`).
   - Соблюдается шкала билборд-типографики для гарантированной читаемости на мобильных экранах (заголовки $\ge 50$px, текст карточек $\ge 24$–$28$px).
3. **Единый источник истины:**
   - Веб-разметка, тексты для диктора, тайминги аудио и карточки формируются строго на основе разметки в файлах `docs/presentation_deck.md`.
4. **Инвариант локальной относительной навигации:**
   - Категорически запрещены машинозависимые абсолютные пути вида `/Users/...` или `file:///Users/...`.
   - Все перекрестные ссылки строятся строго локально относительно текущего документа (`./`, `../`, `../../`).
5. **Языковой стандарт и запрет корпоративных местоимений (Правило 12):**
   - Строгий запрет на использование местоимений «мы», «наш», «нами» и производных в документации, слайдах и дикторском тексте. Изложение ведется в академическом, инженерном или институциональном ключе.
6. **Концептуальная точность суверенитета данных:**
   - Термин «суверенитет» применяется строго в контексте Отечества, государства и национальной информационной безопасности.
   - Данные граждан хранятся децентрализованно на их устройствах («Листах») в реляционной СУБД SQLite без концентрации на внешних серверах.
